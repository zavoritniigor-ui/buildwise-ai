# Дослідження джерел даних (Фаза 0)

**Дата перевірки:** 14 листопада 2026 року  
**Статус:** попередній. Це технічний огляд, а не юридичний висновок.

## Підсумок

- Масовий автоматичний збір із сайтів виробників і магазинів не можна вважати
  дозволеним. Там, де умови вдалося прочитати, вони його прямо забороняють.
- Реалістичні законні шляхи до цін: комерційна угода з Buildsavr, партнерські
  товарні фіди магазинів, пряма домовленість із мережею.
- Технічні характеристики можна вносити як факти з посиланням на офіційний
  документ. Копіювати самі документи, зображення й описи не можна без дозволу.

## Що вдалося прочитати

### Schluter Canada

Джерело: <https://www.schluter.ca/schluter-ca/en_CA/terms_and_conditions>
(редакція від 26 січня 2021 року; розділи 1–14 прочитано дослівно).

- Автоматизований доступ заборонено. Серед забороненого названо «using or
  launching any automated system», зокрема роботів і павуків.
- Вміст призначений лише для особистого некомерційного використання. Копіювання,
  перепублікація та використання на іншому сайті заборонені.
- API, товарного фіду чи ліцензування даних на сайті не описано.
- Сторінка завантажень відкрита без входу й містить технічні паспорти, проте це
  не скасовує обмежень вище.

### Buildsavr (Bâtir à Rabais inc.)

Джерела: <https://buildsavr.com/pricing>, <https://buildsavr.com/terms>
(умови оновлено 5 листопада 2026 року).

| План              | Ціна, CAD                  | Порівнянь       |
| ----------------- | -------------------------- | --------------- |
| Free              | 0                          | 5 на місяць     |
| Self-build pass   | 199 одноразово             | 200 загалом     |
| Builder Homeowner | 16,99 на місяць            | 100 на місяць   |
| Builder Pro       | 79 на місяць               | 500 на місяць   |

- MCP-сервер є на всіх планах, але на стандартних він лише для особистих або
  внутрішніх потреб.
- Показ їхніх цін у чужому продукті, перепродаж, створення похідної бази вимагають
  попереднього письмового дозволу. Для цього призначений план Custom.
- Масове автоматичне вилучення даних заборонено.
- Власні ціни Buildsavr, за їхніми умовами, походять із публічних джерел:
  флаєрів, партнерських фідів і результатів пошуку від авторизованих постачальників.

## Що прочитати не вдалося

| Сайт              | Результат                                              |
| ----------------- | ------------------------------------------------------ |
| RONA              | Сторінка умов повертає 403 для автоматичного запиту    |
| Home Depot Canada | Тайм-аут                                               |
| BMR               | 403                                                    |
| Canac             | Сторінка формується скриптами, тексту умов не отримано |
| MAPEI Canada      | 403                                                    |

Зміст цих умов **невідомий**. Сам факт блокування показує, що сайти активно
захищаються від автоматичних запитів. Ці сторінки потрібно прочитати вручну в
браузері перед будь-яким рішенням.

Додаткове спостереження: `robots.txt` у BMR перелічує окремі карти сайту для
товарів і категорій, у RONA та Home Depot Canada є загальна карта сайту. Карта
сайту показує, які сторінки існують, але не дає дозволу на комерційне
використання їхнього вмісту.

## Рішення для проєкту

1. Колектори не обходять захист від ботів і не збирають дані із сайтів, чиї
   умови це забороняють або ще не прочитані.
2. Пілот на перших товарах наповнюється вручну: характеристика, значення,
   посилання на офіційний документ, сторінка. Схема бази це вже підтримує.
3. Таблиця пропозицій магазинів лишається порожньою, доки немає законного
   джерела цін. Застосунок показує «ціна невідома» та посилання на товар.
4. Кожен запис пропозиції має поле джерела даних, щоб можна було довести
   походження кожної ціни.

## Відкриті дії для власника проєкту

- Написати Buildsavr на `partenaires@batirarabais.ca` щодо плану Custom та умов
  показу цін у BuildWise.
- Перевірити партнерські програми RONA та Home Depot Canada і чи дають вони
  товарний фід із цінами.
- Запитати в Schluter і MAPEI дозвіл на використання технічних даних або
  дізнатися про офіційні канали для розробників.
- Прочитати в браузері умови RONA, Home Depot Canada, BMR, Canac і MAPEI та
  доповнити цей документ.
- Перед комерційним запуском отримати консультацію юриста в Квебеку.
